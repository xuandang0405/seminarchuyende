## 2. Quy Chuẩn Đơn Vị & Kiểu Dữ Liệu (SI Standards)
- **Cự ly đường chim bay**: `straight_line_distance_m` (Số thực hoặc số nguyên mét, chuẩn SI).
- **Cự ly đường bộ**: `route_distance_m` (Mét nguyên, OSRM road network).
- **Thời gian di chuyển**: `route_duration_s` (Giây nguyên, OSRM duration).
- **Định dạng hiển thị người dùng (UI Formatted Strings)**:
  - Dưới 1,000 m: hiển thị `X m` (ví dụ: `350 m`).
  - Từ 1,000 m trở lên: hiển thị `Y.Y km` (ví dụ: `1.2 km`).
  - Thời gian: `Math.ceil(seconds / 60)` phút (ví dụ: `5 phút`).
- **GeoJSON**: Lưu trữ MongoDB theo chuẩn `[longitude, latitude]`. Trả về API có đầy đủ `latitude` và `longitude` độc lập để Client Web & Mobile không bao giờ bị nhầm lẫn kinh độ / vĩ độ.

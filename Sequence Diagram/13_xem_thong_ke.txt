Web [label: "Web Admin hoặc Owner", color: blue]

Service [label: "Analytics Read Service", color: purple]

Web > Router: Yêu cầu thống kê theo thời gian và POI
Router > Router: Xác thực phiên và kiểm tra tham số
Router > Service: Chuyển yêu cầu cùng danh tính và quyền
Service > Repo: Xác định phạm vi POI người dùng được phép xem
Repo > DB: Đọc dữ liệu sở hữu và phạm vi cần thiết
DB --> Repo: Danh sách POI hợp lệ
Repo --> Service: Phạm vi cho phép
alt [label: "Yêu cầu nằm ngoài phạm vi được phép"] {
  Service --> Router: Từ chối truy cập
  Router --> Web: 403 Forbidden
}
else [label: "Được phép xem"] {
  Service > Repo: Đọc read model theo kỳ và phạm vi đã kiểm tra
  Repo > DB: Truy vấn các collection chỉ số tổng hợp
  DB --> Repo: Số liệu và thời điểm cập nhật
  Repo --> Service: Kết quả đọc
  Service > Service: Tính tỷ lệ hoặc trung bình với mẫu số phù hợp
  Service --> Router: Kết quả thống kê cùng độ mới dữ liệu
  Router --> Web: 200 và dữ liệu dashboard
}
